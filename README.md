Se desarrolló una SPA llamada BookList utilizando Vue.js y Vue Router.
La aplicación permite agregar, visualizar y eliminar libros de manera interactiva.
Se utilizaron componentes reutilizables, formularios con v-model, directivas como v-if, v-show y v-for, además de eventos con @click, @submit.prevent y teclado con Enter.
También se implementaron rutas para Inicio, Lista de libros y Detalle del libro mediante rutas dinámicas.
El proyecto fue organizado de manera modular para facilitar su mantenimiento y escalabilidad.
